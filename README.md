# 💬 OT3ChatApp – Real-Time Chat Application

OT3ChatApp is a **real-time chat application** inspired by popular messaging platforms such as Zalo.
The project was developed as a **team project** to practice building a full-stack chat system on **Mobile** using modern technologies.

---

## 📱 Features

### 👤 Authentication & User Management

* User registration with **OTP verification**
* Login / Logout
* Forgot password
* Update personal profile (avatar, name, gender, birthday)

### 💬 Chat Features

* **One-to-one chat** and **group chat**
* Send **text messages, images, videos, and files**
* Emoji and reactions
* **Message recall** and **message deletion**
* Pin important messages

### 👥 Social Features

* Search users by **email or phone number**
* Send / accept / reject friend requests
* Friend list management
* Create, join, and manage group chats
* Add / remove group members
* Leave or dissolve groups

> **Note:** Some features (e.g. video call) are planned but not fully implemented yet.

---

## 🛠️ Tech Stack

### Frontend

* **React Native** (Mobile Application)
* **JavaScript**

### Backend & Services

* **Node.js**
* **Socket.io** – real-time messaging
* **Firebase Authentication** – user authentication & OTP
* **AWS DynamoDB** – user & message data storage
* **AWS S3** – image & media storage

### Tools

* Git, GitHub
* Visual Studio Code
